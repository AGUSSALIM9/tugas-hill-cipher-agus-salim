Enkripsi Hill Cipher

Penjelasan dan penyelesaian lengkap enkripsi Hill Cipher 2 × 2, dihitung per pasangan huruf.

Nama: AGUS SALIM NIM: 524012001 Prodi: ILMU KOMPUTER Tugas: 3
Modulus 26 A = 0, B = 1, …, Z = 25 Rumus C = K × P (mod 26)

Jawaban tugas

Semua tahapan perhitungan untuk kedua soal.

Flowchart proses enkripsi

Alur program Hill Cipher 2 × 2, mulai dari validasi input hingga menghasilkan cipherteks.

Coba enkripsi sendiri

Masukkan plainteks dan empat angka kunci. Spasi akan diabaikan; jika jumlah huruf ganjil, program menambahkan X.

Kesimpulan

  1. HILL CIPHER TIDAK SULIT menghasilkan cipherteks FMRDGCNZSHNKPGCWKVYV.
  2. SAYA PUSING menghasilkan cipherteks MUQSBDYSJF.

Catatan: determinan kunci soal pertama adalah 3 dan tidak memiliki invers modulo 26. Ini tidak menghalangi enkripsi, tetapi kunci tersebut tidak dapat digunakan untuk dekripsi Hill Cipher standar secara unik.
